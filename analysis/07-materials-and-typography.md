# 首屏材质与字体：问题分析、修复及验证

2026-11-13 · 修改项目：C:\Users\Administrator\Desktop\anthropic-article

参考：[Anthropic 发布页面](https://www.anthropic.com/claude-fable-and-mythos-5-1)。本轮先比较实时参考、上轮实现与字体矩形，再修改材质和排版。

## 问题与处理

| 对象 | 原有问题 | 本轮修复 |
|---|---|---|
| 月亮 | 随机噪声无法表现月海分布；月面明暗缺少可信结构 | 使用 NASA LRO/LROC 的 2048×1024 月面色彩数据，以球面经纬映射呈现真实月海和撞击坑；保留月相明暗、大气衰减与轻微天平动 |
| 云 | 二维碎纹形成扁平、均匀的云块，灰影与参考页粉金色有偏差 | 生成 64³ 三维噪声 atlas，8 步前后密度积分模拟厚度、透射和局部自阴影；调整横向云丝、边缘破碎程度及粉紫阴影/淡金受光色 |
| 树枝 | 直线拼接、均匀宽度和棕色平面块，缺少树皮光照 | 5 条二次 Bézier 枝条，每条 8 段并渐细；沿枝条映射树皮颜色与法线纹理，加圆柱表面光照、蓝灰环境色和按深度变化的虚化 |
| 字体 | Georgia 和系统字体的字形、连字、字宽不同；日期大写和字距也不符 | 本地加载 Anthropic Serif 正体/斜体、Sans 正体可变字体，恢复 :Claude: 连字；修正日期大小写、字重、字号、行高及目录高度 |

移除了整张 canvas 的统一 CSS 模糊，让月面保留细节、枝条独立虚化。纹理加载包含默认纹理与加载结果标记，避免加载过程中画面不可用。

## 验证结果

- 1440×900 CSS 视口下，日期、标题两行、目录的 x/y/width/height 与实时参考矩形最大差值为 **0.0 CSS px**。该结论仅指这些排版矩形，并不代表全页面像素一致。
- Noon → Night → Morning → Noon 均可切换，夜景星点、月面、云层与晨景配色正常，已回到 Noon。
- 390×844 CSS 视口下，无横向溢出，标题和目录可读；材质加载状态为 `ready`。桌面和手机控制台均无 warning/error。
- HTML、CSS、两个 JS 和全部 7 个字体/纹理资产均返回 HTTP 200；两个 JS 的 `node --check` 均通过。
- 浏览器截图实际导出为桌面 1425×891、手机 375×811；CSS 测量仍基于上述指定视口，不将导出图尺寸混作布局测量值。

## 仍存在的具体差异

云的外轮廓、密度场与运动相位属于重建，参考页更细腻的层叠云边并未逐像素复现。枝条使用曲线距离场与近似表面光照，未复用参考页的三维 mesh 或景深后处理，因此分叉位置、遮挡和虚化形状仍有差别。NASA 月面真实纹理提升了材质可信度，但与参考页选择的月面旋转、精确月相和后处理并不完全相同。

页头导航结构、小鸟模型以及未实现的正文章节属于之前已记录的范围差异，本轮没有扩展这些模块。

## 资产来源

- 字体与树皮颜色/法线资产来自参考页，具体文件来源记录在项目 `assets/README.md`。这些资源没有经核实的开放再分发许可，本项目仍作为本地复刻学习使用。
