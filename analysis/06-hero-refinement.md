# 首屏场景优化 · 2026-11-13

参考页：https://www.anthropic.com/claude-fable-and-mythos-5-1

本轮重新打开参考页，针对首屏背景进行原创 GLSL 重建。早期代码将 Noon 月亮设为零，与本次实际观察到的右上亏凸月不符，现已修正。

## 改动

- 云层：用多个独立云团建立边缘构图，叠加五层旋转噪声、域扭曲与细碎云丝；根据邻域密度计算受光和阴影，保留中央文字区。风位移有界，长时间运行不会将全部云团移出画面。
- 月亮：加入按画面比例校正的球面、月相、天空透射，以及三个尺度的重叠坑纹。手机尺寸缩小月亮，避免抢占标题区。
- 树枝：将等宽线段替换为渐细的分叉和不同景深的虚化，补充轻微风摆。
- 山雀：补上黑帽、白颊、黄腹、蓝灰羽翼、眼睛、喙与足；修正飞行时的朝向和两次飞行之间的等待时间。
- 运行：切换过渡使用实际帧间时间；限制片元缓冲宽度和像素比；减弱时间噪点；着色器失败时显示 CSS 兜底。减少动态效果时，切换和调整窗口后会重新绘制静帧。
- 手机：隐藏无法完整放下的桌面导航，消除水平溢出；保留 Logo 和 Try Claude。

## 验证

- JavaScript 语法检查通过，页面及 CSS、JavaScript 返回 HTTP 200。
- 浏览器中检查白天、夜晚与清晨切换；选中状态同步更新，场景颜色正常过渡。
- 1440×900 桌面与 390×844 手机尺寸检查；手机无水平溢出。
- 浏览器未报告着色器编译错误或 JavaScript 异常。
- 保存参考、原版和优化后截图。云与鸟为动态场景，截图相位不同，不作逐像素一致性声明。

## 保留差距

云团仍为二维程序绘制，月表为原创程序纹理，树枝与鸟为形状绘制。与参考页的真实几何、PBR 材质及景深仍有差距；专有字体和页头也仍使用原有替代方案。本轮未扩展正文章节。
